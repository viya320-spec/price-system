# price-system

守葳體系醫美價目表系統

## 檔案說明
- `index.html` — 畫面／介面（白底、大字級、老花友善版本）。**平常不需要更動**，除非要新增功能或分類。
- `data.js` — 所有價目資料（項目、常態套組、猛健樂、檔期活動、儲值、產品、體驗價）。**每月更新只需要換這個檔案**。

## 每月更新方式
1. 把新的 PDF 價目表交給處理的人（或 Claude），依照既定邏輯解析成 `data.js` 格式
2. 確認新舊資料比對清單（新增／異動／疑似下架項目）沒有問題
3. 覆蓋這個 repo 裡的 `data.js`，push 上去
4. GitHub Pages 會在幾分鐘內自動更新線上版本，`index.html` 不需要動

## 資料版本
目前版本：見 `data.js` 檔案開頭的 `DATA_VERSION`
