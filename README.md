# price-system

守葳體系醫美價目表系統

## 檔案說明
- `index.html` — 畫面／介面（白底、大字級、老花友善版本）。**平常不需要更動**，除非要新增功能或分類。
- `data.js` — 所有價目資料（項目、常態套組、猛健樂、檔期活動、儲值、產品、體驗價）。**每月更新只需要換這個檔案**。
- `README.md` — 這份文件，給維護系統的人看。
- `使用手冊.md` — 給業務同事看的操作說明（搜尋、收藏常用品項、看懂警示標籤）。

## 目前功能（8個分頁）
1. **❤️ 自訂販售** — 業務同事可以把常賣的品項收藏起來，方便快速查找。收藏清單存在使用者自己手機的瀏覽器裡（localStorage），不同人不會互相干擾，也不需要登入。清除瀏覽器資料或換手機會導致收藏清單重置。
2. **📋 項目** — 依分類／子分類瀏覽單項療程
3. **🗂 常態套組** — 依分類瀏覽套組，含警示標籤（限購一組／不可扣儲值／不可轉贈等）
4. **💉 猛健樂**
5. **🎁 檔期/活動** — 有檔期日期的促銷套組
6. **💳 儲值** — 醫美療程儲值 vs 產品儲值分開列示
7. **🧴 產品** — 分類→子分類（單品項目／套組優惠）結構，套組優惠用套組卡片呈現
8. **🎫 體驗價**

右上角 🔍 可用 S編號 或關鍵字全域搜尋；A+ 可放大字級（老花友善）。

## 每月更新方式
1. 把新的 PDF 價目表交給處理的人（或 Claude），依照既定邏輯解析成 `data.js` 格式（詳見交接時提供的「更新流程說明」文件）
2. 確認新舊資料比對清單（新增／異動／疑似下架項目）沒有問題
3. 覆蓋這個 repo 裡的 `data.js`，push 上去
4. GitHub Pages 會在幾分鐘內自動更新線上版本，`index.html` 不需要動
